## Explore a new workspace
Start by browsing dashboards to view centralized intelligence data, then
use the graph explorer to traverse relationships and see how entries are
connected. As you work, create and edit notes to link related data
automatically. Use enrichment when you need external context for a specific
artifact, and use a digest when you need to ingest a structured dataset so
those external findings become first-class graph entries you can explore and
connect.

## Investigate a new case
Create the entity to anchor the case, capture initial notes and artifacts,
and use the graph to track how evidence connects over time. As new leads
appear, add or refine links in your notes to keep the case cohesive and easy to
hand off. When you need more context on a key artifact, run an enrichment
request from the case notes so the artifact list and associated entities are
captured automatically. If you receive a report or dataset from another team,
use a digest to ingest it and connect it back to the case entity.

## Produce a publishable report
Curate the relevant notes, order them to match the narrative you want, choose
anonymization settings, and export or publish the report. If you are
publishing to another CRADLE instance or Catalyst, use the appropriate output
format and verify the rendered report once the job completes.
