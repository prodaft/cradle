## Explore a new workspace
- Browse dashboards to view centralized intelligence data.
- Use the graph explorer to traverse relationships.
- Create and edit notes to link related data automatically.

## Investigate a new case
- Create the entity.
- Capture initial notes and artifacts.
- Explore relations in the graph.

## Produce a publishable report
- Curate relevant notes.
- Choose anonymization settings.
- Export or publish the report.
