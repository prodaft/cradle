## Profile and sessions
- Update profile details and preferences.
- Review active sessions and sign out other devices if needed.

## API keys
- Generate an API key for programmatic access.
- Rotate keys if they are exposed or shared.

## Two-factor authentication
- Enable 2FA for additional account security.
- Store recovery details securely.

## Editor preferences
- Set a default note template.
- Enable or disable Vim mode.
- Choose a theme (light or dark).
