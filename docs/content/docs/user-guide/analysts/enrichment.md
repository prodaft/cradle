Enrichment adds related context to artifacts by running external or internal
processors and creating new related entries and relations.

## Requesting enrichment
- Select one or more artifacts and open the enrichment flow.
- Choose the enrichers to run for the request.
- Submit the request and monitor status.

## Viewing results
- Results appear as new entries and relations linked to the original artifacts.
- Each relation stores the reason and any metadata returned by the enricher.
- Related notes and graph views update automatically once results are saved.

## Warnings and errors
- Warnings indicate partial failures but still return usable results.
- Errors indicate the request or enricher failed to complete.
- Retry a failed request after correcting configuration or connectivity issues.

## Notifications
- You receive a notification when the enrichment completes or fails.
