The publish view is the central interface for managing and publishing reports.
You can browse existing reports or create new ones.

## Report management
- Browse reports with pagination.
- View report details.
- Open report URLs in a new tab.
- Edit existing reports.
- Retry report generation after failures.
- Delete reports.
- Initiate new report creation.

## Creating and editing a report

- Report title management
  Set or update the report title before publishing.

- Selecting notes
  - Search notes by content or author.
  - Drag and drop notes into the report.
  - Reorder notes via drag and drop.
  - Remove notes that are no longer relevant.

- Report mode
  Switch between anonymized and transparent modes.

## Publishing strategies

- Download option
  Export HTML, JSON, or plaintext locally.

- Upload option
  Upload the report to a remote service (for example, Catalyst).

- Real-time preview
  Preview the report layout before submission.

- Submit or update
  Submitting starts a background compilation job. You are notified when it
  completes or if an error occurs.

## Notifications and job status
- Reports are compiled by a background job.
- Notifications indicate success or failure.
