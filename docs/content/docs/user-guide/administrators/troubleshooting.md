## Access problems
- Verify entity-level access for the affected user.
- Check whether notes reference any inaccessible entities.

## Report errors
- Inspect report status and error messages.
- Retry generation after fixing missing notes or storage issues.

## Enrichment failures
- Validate enricher credentials and endpoints.
- Re-run enrichment after dependencies recover.
