## Two-factor enforcement
- Require 2FA for privileged users.
- Review recovery workflows regularly.

## API key lifecycle
- Rotate keys on a schedule.
- Revoke keys when users leave or roles change.

## Access reviews
- Perform periodic access audits.
- Ensure separation of duties between admins and analysts.
