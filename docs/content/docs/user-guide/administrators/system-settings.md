System settings are stored in the management subsystem and control defaults for
notes, users, and file handling.

## Notes settings
- Minimum entries and entities required for a note.
- Max clique size for reference graph operations.
- Allow or block dynamic entry class creation.

## User settings
- Require admin confirmation for new accounts.
- Require email confirmation for activation.
- Allow or block self-registration.

## File settings
- Upload limit and per-user overrides.
- Auto-process files after upload.
- Hash subtype mappings and max file size for hashing.
