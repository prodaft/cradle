Key objects in CRADLE include:

- **Entry** as the core unit representing an entity or artifact.
- **Entity** as a high-level object under investigation.
- **Artifact** as a specific piece of evidence such as an IP or hash.
- **Note** as a document tied to one or more entries.
- **Relation** as an automatically generated link between entries from note
  content.
- **Entry class** as the categorization for entries, with type, subtype, and
  validation rules.
