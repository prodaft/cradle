Key objects in CRADLE include:

- Entry: the core unit, representing an entity or artifact.
- Entity: a high-level object under investigation.
- Artifact: a specific piece of evidence such as an IP or hash.
- Note: a document tied to one or more entries.
- Relation: an automatically generated link between entries from note content.
- Entry class: categorization for entries, with type, subtype, and validation
  rules.
