CRADLE generates reports from selected notes and stores results as
PublishedReport records.

## Strategies
- Download formats include HTML, plaintext, and JSON.
- Upload strategies can publish to external systems.

## Status lifecycle
- Working: report generation is in progress.
- Done: report is ready and stored.
- Error: report failed and includes an error message.
