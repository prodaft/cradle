Files UI supports uploads, metadata display, and downloads.

## Upload flow
- Upload forms and modal dialogs manage file selection.
- Uploads can be attached to notes and digests.

## Metadata display
- Hashes and file details are shown in file lists.
- Download actions respect access controls.
