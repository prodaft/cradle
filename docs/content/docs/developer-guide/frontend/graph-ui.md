The graph explorer UI provides controls for query mode, depth, and filtering.

## Key components
- GraphExplorer renders the graph workspace.
- GraphSearch provides query input and filters.
- GraphControl handles layout and visibility controls.

## Interaction patterns
- Expand nodes to explore neighbors.
- Click edges to view related notes.
